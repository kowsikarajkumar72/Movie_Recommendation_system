# 🎬 Movie Recommendation System

An NLP-based **Movie Recommendation System** that recommends movies based on a user's recently watched movies.

The project compares two different text-embedding approaches:

* **Word2Vec**
* **Sentence Transformer (`all-MiniLM-L6-v2`)**

The recommendations are generated by calculating **cosine similarity** between movie embeddings.

## 📌 Project Overview

The goal of this project is to build a personalized movie recommendation system using movie metadata such as:

* Movie title
* Genres
* Movie overview

The project experiments with traditional word-level embeddings and modern transformer-based sentence embeddings to determine which approach provides more relevant recommendations.

## 🗂️ Dataset

### Movie Dataset

The movie dataset contains **4,803 movie records** with 3 main features:

* `title` – Movie name
* `overview` – Movie description
* `genres` – Movie genres

Missing values were removed before building the recommendation models.

### Evaluation Dataset

The evaluation dataset contains **2,000 records** and includes:

* `movie_1` to `movie_7` – Recently watched movies
* `movie_watch` – Movie currently watched by the user
* `past_success` – Indicates whether a previous recommendation was successful
* `date` – Evaluation date

## 🧹 Data Preprocessing

For the Word2Vec approach, the following movie information was combined:

```text
Title + Genres + Overview
```

The text was tokenized using `simple_preprocess()` before training the Word2Vec model.

Missing movie records were removed and the dataset index was reset.

## 🧠 Model 1 — Word2Vec

A Word2Vec model was trained using the movie text data.

### Parameters

```python
Word2Vec(
    vector_size=100,
    window=5,
    min_count=1,
    workers=4,
    seed=42
)
```

The word embeddings were averaged to create a single vector representing each movie.

The average embeddings of recently watched movies were then compared with other movie embeddings using cosine similarity.

### Result

The Word2Vec model achieved approximately **17%–27% monthly recommendation success**, showing moderate performance.

## 🤖 Model 2 — Sentence Transformer

The second approach uses a pretrained Sentence Transformer:

```text
all-MiniLM-L6-v2
```

The model generates semantic embeddings using the movie:

```text
Title + Genres + Overview
```

The embeddings of recently watched movies are averaged and compared with other movies using cosine similarity.

### Result

The Sentence Transformer achieved an average recommendation success rate of:

### **64.75% 🎯**

The monthly success rate remained approximately between **62% and 68%**, showing strong and consistent performance.

## 📊 Model Comparison

| Model                     | Performance |
| ------------------------- | ----------: |
| Past Recommendation Model |      ~13.5% |
| Word2Vec                  |    ~17%–27% |
| Sentence Transformer      |  **64.75%** |

The Sentence Transformer significantly outperformed the Word2Vec-based approach and the previous recommendation model.
